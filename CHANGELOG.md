# Release Notes for Discontent

## Unreleased

### Added
- **Fields** tool: Craft’s Settings → Fields list with a field-type dropdown (used types only), an **Unused** toggle, search, sort, double-click-to-edit slideout, delete, and “New field”.
- **Entry Types** tool: usage filter (Section Entries / Matrix entries / Nested CKEditor entries), an **Unused** toggle, search, sort, double-click slideout, delete, and “New entry type”.
- Canonical pages at `/discontent/*` with an in-page sidebar; native Settings → Fields / Entry Types redirect there when **Replace native pages** is on.
- Shareable filtered URLs — filter state is reflected in query params.
- Settings: **Plugin name**, **Replace native pages**, **Show in main navigation**, and **Default view**.
