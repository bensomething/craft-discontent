# Release Notes for Discontent

## 1.0.0-beta.3 - 2026-11-17

- Added a **Sites** column to the Sections page on multi-site installs, and searching Sections now matches site names.
- Added a **Translation Method** column to the Fields page on multi-site installs, with **Translatable** / **Not translatable** views.
- The toolbar’s dropdowns now share the search’s row until there’s no room for them.
- Double-clicking a row to open it no longer selects its text.

## 1.0.0-beta.2 - 2026-11-16

- Added an **Entry Types** column to the Sections page, and searching Sections now matches entry type names.
- The Fields page’s **Used by** column now shows a field’s layouts as chips, the first plus a “+N” for the rest, instead of a count.

## 1.0.0-beta.1 - 2026-11-15

- Initial release.
